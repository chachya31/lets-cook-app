# Code Review Hook

このフックは手動でコードレビューを実行します。

## トリガー
- イベント: ユーザーがコードレビューを要求
- コマンド: `レビュー`, `code review`, `review this`

## レビュー観点

### 1. コーディング規約の遵守
- Javaファイル: Logger直接定義、@Value使用
- TypeScriptファイル: apiClient.ts使用、型定義

### 2. セキュリティ
- 機密情報のログ出力チェック
- SQLインジェクション対策
- XSS対策

### 3. パフォーマンス
- 不要なループ
- 非効率なデータベースクエリ
- メモリリーク

### 4. 可読性
- 適切な変数名
- コメントの適切性
- 関数の責任分離

### 5. テスタビリティ
- 依存関係の注入
- モック化の容易性
- テストカバレッジ

## アクション
指定されたファイルまたは最近変更されたファイルをレビューし、改善提案を提示します。

---

**設定方法**: 
Kiro IDEのコマンドパレット（Ctrl+Shift+P / Cmd+Shift+P）から「Open Kiro Hook UI」を選択し、以下の設定を追加してください：

```
Trigger: On Message Sent
Message Pattern: (レビュー|code review|review)
Action: Send Message to Agent
Message: 
最近変更されたファイルまたは指定されたファイルをレビューしてください。

レビュー観点：
1. コーディング規約の遵守
2. セキュリティ（機密情報のログ出力など）
3. パフォーマンス
4. 可読性
5. テスタビリティ

問題があれば具体的に指摘し、改善案を提示してください。
良い点も積極的に評価してください。
```
