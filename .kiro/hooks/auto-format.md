# Auto Format Hook

このフックはコードの自動フォーマットを実行します。

## トリガー
- イベント: ユーザーがフォーマットを要求
- コマンド: `フォーマット`, `format`, `整形`

## フォーマット内容

### Javaファイル
- インデント: 4スペース
- 行の最大長: 120文字
- import文の整理
- 未使用のimport削除

### TypeScriptファイル
- インデント: 2スペース
- 行の最大長: 100文字
- セミコロン: あり
- シングルクォート使用
- import文の整理

## アクション
指定されたファイルまたは最近変更されたファイルをフォーマットします。

---

**設定方法**: 
Kiro IDEのコマンドパレット（Ctrl+Shift+P / Cmd+Shift+P）から「Open Kiro Hook UI」を選択し、以下の設定を追加してください：

```
Trigger: On Message Sent
Message Pattern: (フォーマット|format|整形)
Action: Send Message to Agent
Message: 
最近変更されたファイルまたは指定されたファイルをフォーマットしてください。

フォーマット基準：
- Javaファイル: インデント4スペース、行の最大長120文字
- TypeScriptファイル: インデント2スペース、行の最大長100文字
- import文の整理と未使用のimport削除
- コーディング規約に従った整形

フォーマット後、変更内容を報告してください。
```
